# Mario Runner (HTML, CSS e JavaScript)

Jogo de corrida inspirado na mecânica do Dino do Chrome, com personagem pixelado desenhado em JavaScript.

## Como executar no VS Code
1. Extraia a pasta `dino` para a Área de Trabalho.
2. Abra o VS Code.
3. Vá em **Arquivo > Abrir Pasta** e selecione `Área de Trabalho\dino`.
4. Abra `index.html`.
5. Execute com a extensão **Live Server** (clique com o botão direito em `index.html` > **Open with Live Server**). Também pode abrir o `index.html` diretamente no navegador.

## Controles
- **Espaço**, **Seta para cima** ou **W**: pular.
- **Clique/toque** na área do jogo: pular.
- Ao perder, pressione uma tecla de pulo ou clique em “Jogar novamente”.

## Funcionalidades
- Obstáculos variados (cactos e inimigos).
- Pontuação e recorde salvos no navegador.
- Velocidade aumenta progressivamente.
- Layout adaptável a celular e computador.
- Não precisa instalar bibliotecas nem baixar imagens.
